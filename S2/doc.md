# Вариант №2. Сервис профилей (Profile Service)

## Создание профиля

### Информация требуемая для создания профиля пользователя

|Параметр|Обязательность|Тип|Ограничение|Значение по умолчанию|Пояснение|
|----------|----------------|-----|-------------|----------------------|-------------|
|first_name|Не обязательно|Строка|—|None|Имя|
|last_name|Не обязательно|Строка|—|None|Фамилия|
|middle_name|Не обязательно|Строка|—|None|Отчество|
|user_id|Обязательно|Целое число|Уникальный, внешний ключ|—|id пользователя|
|email|Обязательно|Строка|Уникальный, формат почты|—|Почта|
|phone_number|Не обязательно|Строка|Уникальный, формат телефона|None|Номер телефона|
|avatar|Не обязательно|Строка|формат URL|None|Аватарка|
|notification|Не обязательно|Логический|—|True|Статус уведомлений|

### Выходные данные

|Параметр|Тип|
|----------|-----|
|id|Целое число|
|first_name|Строка|
|last_name|Строка|
|middle_name|Строка|
|user_id|Целое число|
|email|Строка|
|phone_number|Строка|
|avatar|Строка|
|notification|Логический|
|is_active|Логический|

## Удаление профиля по ID

Установит значение False в поле is_active в записи из таблицы профилей, а потом вернет True, если профиль был успешно переведен в неактивное состояние, иначе вернет False
